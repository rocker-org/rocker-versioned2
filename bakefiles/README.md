# Build configuration files for the `docker buildx bake` command

:warning: JSON files except `devel.docker-bake.json` in this directory are generated by
[`generate-bakefiles.R`](../build/scripts/generate-bakefiles.R),
**Don't edit manually.** :warning:

The Bake files are the source of truth for build targets, platforms, and image tags.
The core GitHub Actions workflow publishes each platform by canonical digest and only
assigns these tags after every platform for a target has succeeded. The Makefile Bake
targets remain available for local development and validation; they are not the
production publish orchestrator.
